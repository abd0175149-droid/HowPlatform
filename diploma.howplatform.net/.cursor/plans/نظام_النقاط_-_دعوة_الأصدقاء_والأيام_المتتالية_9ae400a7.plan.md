# نظام النقاط - دعوة الأصدقاء والأيام المتتالية

## نظرة عامة

نظام مكافآت يمنح المستخدمين نقاطاً عند:

1. **دعوة صديق** - 100 نقطة عند إكمال صديق دعوته لبروفايله
2. **الدخول لخمسة أيام متتالية** - 50 نقطة كل 5 أيام

---

## البنية المعمارية

### 1. قاعدة البيانات

#### جدول `rewards_users`

يحتوي على إجمالي نقاط كل مستخدم:

```sql
- id (INT, PK)
- user_id (INT) - FK إلى users.id
- total_points (INT) - إجمالي النقاط (افتراضي 0)
- created_at, updated_at
```

#### جدول `rewards_transactions`

سجل جميع معاملات النقاط:

```sql
- id (INT, PK)
- user_id (INT) - FK إلى users.id
- points (INT) - عدد النقاط (+ أو -)
- reward_type (VARCHAR) - 'friend_invite' أو 'consecutive_days' أو 'ai_tool_usage'
- reward_type_id (INT, NULL) - مرجع للعملية (مثل referral_id)
- description (TEXT) - وصف العملية
- created_at
```

#### جدول `rewards_referrals`

سجل دعوات الأصدقاء:

```sql
- id (INT, PK)
- referrer_user_id (INT) - صاحب كود الدعوة
- referred_user_id (INT) - المستخدم المدعو
- status (ENUM) - 'pending', 'completed', 'rewarded'
- referral_code (VARCHAR) - كود الدعوة (مثل: REF12345678)
- created_at
- completed_at (TIMESTAMP, NULL) - تاريخ إكمال البروفايل
- rewarded_at (TIMESTAMP, NULL) - تاريخ منح النقاط
```

#### جدول `rewards_consecutive_days`

تتبع الأيام المتتالية:

```sql
- id (INT, PK)
- user_id (INT) - FK إلى users.id
- current_streak (INT) - عدد الأيام المتتالية الحالية
- last_login_date (DATE, NULL) - آخر تاريخ تسجيل دخول
- last_rewarded_streak (INT) - آخر streak تم مكافأته
- created_at, updated_at
```

#### جدول `rewards_daily_logins`

سجل تسجيلات الدخول اليومية:

```sql
- id (INT, PK)
- user_id (INT) - FK إلى users.id
- login_date (DATE) - تاريخ تسجيل الدخول
- created_at
- UNIQUE KEY (user_id, login_date) - منع التكرار
```

```php
$diplomaUser = diploma_users WHERE user_id = $referredUserId

    return false  // البروفايل غير مكتمل

    WHERE referred_user_id = $referredUserId 
    AND status = 'pending'

    return false  // لا توجد دعوة
}

// 3. التحقق من عدم منح المكافأة مسبقاً
```

### المرحلة 2: تحديث Streak

**الملف:** `app/Services/RewardsService.php::updateConsecutiveDays()`

```php
// 1. حساب اليوم الحالي (Asia/Amman)
$tz = new DateTimeZone('Asia/Amman')
$now = new DateTime('now', $tz)
$today = $now->format('Y-m-d')  // مثال: '2025-01-23'

// 2. جلب أو إنشاء سجل
$record = rewards_consecutive_days WHERE user_id = $userId
// إذا لم يوجد، إنشاء سجل جديد:
//   current_streak = 0
//   last_rewarded_streak = 0
//   last_login_date = NULL

// 3. تسجيل الدخول اليومي (في rewards_daily_logins)
$dailyLoginModel->recordLogin($userId, $today)
// INSERT INTO rewards_daily_logins (user_id, login_date)
// ON DUPLICATE KEY IGNORE  // منع التكرار

// 4. التحقق من آخر تسجيل دخول
$lastLoginDate = $record['last_login_date']
if ($lastLoginDate === $today) {
    return ['streak' => $currentStreak, 'rewarded' => false]
    // تم التسجيل اليوم، لا حاجة للتحديث
}

// 5. حساب Streak الجديد
$newStreak = 1  // افتراضي

if ($lastLoginDate) {
    $lastDate = new DateTime($lastLoginDate, $tz)
    $yesterday = (clone $now)->modify('-1 day')->format('Y-m-d')
    
    if ($lastDate->format('Y-m-d') === $yesterday) {
        // متتالي: زيادة streak
        $newStreak = $currentStreak + 1
    }
    // إذا لم يكن متتالي (فجوة أكثر من يوم)، streak = 1
}

// 6. تحديث Streak
UPDATE rewards_consecutive_days SET
    current_streak = $newStreak,
    last_login_date = $today
WHERE user_id = $userId
```

### المرحلة 3: منح المكافأة (كل 5 أيام)

```php
// 7. التحقق من منح المكافأة
$currentStreak = $newStreak
$lastRewardedStreak = $record['last_rewarded_streak']

if ($currentStreak >= 5 && $currentStreak > $lastRewardedStreak) {
    // حساب عدد المكافآت المستحقة
    // مثال: streak = 12, last_rewarded = 0
    //   rewardsCount = floor((12 - 0) / 5) = 2
    //   يعني: مكافأة عند 5 ومكافأة عند 10
    $rewardsCount = floor(($currentStreak - $lastRewardedStreak) / 5)
    
    if ($rewardsCount > 0) {
        DB Transaction:
          // منح النقاط
          $pointsToAdd = $rewardsCount * 50  // 50 نقطة لكل 5 أيام
          
          UPDATE rewards_users SET total_points = total_points + $pointsToAdd
          
          INSERT INTO rewards_transactions:
              user_id = $userId
              points = $pointsToAdd
              reward_type = 'consecutive_days'
              description = "استخدام المنصة لـ {$currentStreak} أيام متتالية"
          
          // تحديث last_rewarded_streak
          $newRewardedStreak = $lastRewardedStreak + ($rewardsCount * 5)
          UPDATE rewards_consecutive_days SET
              last_rewarded_streak = $newRewardedStreak
    }
}
```

**أمثلة:**

| Streak | last_rewarded | rewardsCount | النقاط | last_rewarded الجديد |

|--------|---------------|--------------|--------|---------------------|

| 5 | 0 | 1 | 50 | 5 |

| 10 | 5 | 1 | 50 | 10 |

| 12 | 10 | 0 | 0 | 10 |

| 15 | 10 | 1 | 50 | 15 |

| 20 | 15 | 1 | 50 | 20 |

| 25 | 20 | 1 | 50 | 25 |

## التفاصيل التقنية

### 1. إنشاء كود الدعوة

**الملف:** `app/Libraries/ReferralSystem.php::generateReferralCode()`

```php
public function generateReferralCode(int $userId): string
{
    // الكود ثابت لكل مستخدم (بناءً على user_id فقط)
    $hash = md5('referral_' . $userId . '_howplatform')
    $code = 'REF' . strtoupper(substr($hash, 0, 8))
    
    return $code
    // مثال: REFA1B2C3D4
}
```

**خصائص الكود:**

- **ثابت:** نفس الكود لكل مستخدم دائماً
- **قابل لإعادة الاستخدام:** يمكن استخدامه عدة مرات
- **فريد:** كل مستخدم له كود مختلف

---

### 2. التحقق من صحة كود الدعوة

**الملف:** `app/Models/RewardsReferralModel.php::validateReferralCode()`

```php
public function validateReferralCode(string $code): ?int
{
    // الطريقة 1: البحث في rewards_referrals
    $referral = rewards_referrals WHERE referral_code = $code
    if ($referral) {
        $referrerUserId = $referral['referrer_user_id']
        // التحقق من وجود المستخدم في diploma_users
        if (diploma_users WHERE user_id = $referrerUserId EXISTS) {
            return $referrerUserId
        }
    }
    
    // الطريقة 2: حساب الكود من جميع المستخدمين
    // (لأن الكود ثابت ويمكن حسابه من user_id)
    $users = diploma_users SELECT user_id
    foreach ($users as $user) {
        $testCode = generateReferralCode($user['user_id'])
        if ($testCode === $code) {
            return $user['user_id']
        }
    }
    
    return null  // الكود غير صالح
}
```

### 3. تسجيل الدعوة

**الملف:** `app/Models/RewardsReferralModel.php::registerReferral()`

```php
public function registerReferral(int $referrerUserId, int $referredUserId, string $code): ?int
{
    // التحقق من عدم وجود دعوة مسبقة
    $existing = rewards_referrals 
        WHERE referrer_user_id = $referrerUserId 
        AND referred_user_id = $referredUserId
    
    if ($existing) {
        return $existing['id']  // إرجاع السجل الموجود
    }
    
    // إنشاء دعوة جديدة
    INSERT INTO rewards_referrals:
        referrer_user_id = $referrerUserId
        referred_user_id = $referredUserId
        status = 'pending'
        referral_code = $code
    
    return insertID()
}
```

**ملاحظات:**

- **UNIQUE KEY** على `(referrer_user_id, referred_user_id)` يمنع التكرار
- نفس المستخدم لا يمكن دعوته مرتين من نفس الشخص
- يمكن دعوة عدة أشخاص بنفس الكود

### 4. حساب Streak

**المنطق:**

```php
// اليوم الحالي
$today = '2025-01-23'

// آخر تسجيل دخول
$lastLoginDate = '2025-01-22'  // أمس

// حساب
$yesterday = '2025-01-22'

if ($lastLoginDate === $yesterday) {
    // متتالي: زيادة streak
    $newStreak = $currentStreak + 1
} else {
    // فجوة: إعادة streak إلى 1
    $newStreak = 1
}
```

**أمثلة:**

| last_login_date | اليوم | النتيجة |

|----------------|-------|---------|

| 2025-01-22 | 2025-01-23 | streak + 1 (متتالي) |

| 2025-01-21 | 2025-01-23 | streak = 1 (فجوة يوم) |

| NULL | 2025-01-23 | streak = 1 (أول مرة) |

| 2025-01-23 | 2025-01-23 | لا تحديث (نفس اليوم) |

### 5. منح مكافأة الأيام المتتالية

**المنطق:**

```php
$currentStreak = 12
$lastRewardedStreak = 5

// حساب المكافآت المستحقة
$rewardsCount = floor((12 - 5) / 5)  // = 1

// النقاط
$pointsToAdd = 1 * 50  // = 50

// تحديث last_rewarded_streak
$newRewardedStreak = 5 + (1 * 5)  // = 10
```

**سيناريوهات:**

**السيناريو 1: أول 5 أيام**

```
اليوم 1: streak = 1, last_rewarded = 0 → لا مكافأة
اليوم 2: streak = 2, last_rewarded = 0 → لا مكافأة
اليوم 3: streak = 3, last_rewarded = 0 → لا مكافأة
اليوم 4: streak = 4, last_rewarded = 0 → لا مكافأة
اليوم 5: streak = 5, last_rewarded = 0 → مكافأة 50 نقطة، last_rewarded = 5
```

**السيناريو 2: الوصول لـ 10 أيام**

```
اليوم 6: streak = 6, last_rewarded = 5 → لا مكافأة
اليوم 7: streak = 7, last_rewarded = 5 → لا مكافأة
اليوم 8: streak = 8, last_rewarded = 5 → لا مكافأة
اليوم 9: streak = 9, last_rewarded = 5 → لا مكافأة
اليوم 10: streak = 10, last_rewarded = 5 → مكافأة 50 نقطة، last_rewarded = 10
```

**السيناريو 3: فجوة في Streak**

```
اليوم 1-5: streak = 5 → مكافأة 50، last_rewarded = 5
اليوم 6: لم يسجل دخول
اليوم 7: streak = 1 (إعادة)، last_rewarded = 5 → لا مكافأة
اليوم 8: streak = 2, last_rewarded = 5 → لا مكافأة

اليوم 12: streak = 6, last_rewarded = 5 → لا مكافأة
اليوم 13: streak = 7, last_rewarded = 5 → لا مكافأة
...
اليوم 15: streak = 9, last_rewarded = 5 → لا مكافأة
اليوم 16: streak = 10, last_rewarded = 5 → مكافأة 50، last_rewarded = 10
```

## إدارة النقاط

### إضافة النقاط

**الملف:** `app/Services/RewardsService.php::addPoints()`

```php
public function addPoints(int $userId, int $points, string $type, ?int $typeId = null, ?string $description = null): bool
{
    DB Transaction:
        // 1. تحديث إجمالي النقاط
        UPDATE rewards_users SET total_points = total_points + $points
        WHERE user_id = $userId
        
        // 2. إضافة معاملة
        INSERT INTO rewards_transactions:
            user_id = $userId
            points = $points  // يمكن أن يكون سالباً للخصم
            reward_type = $type  // 'friend_invite', 'consecutive_days', 'ai_tool_usage'
            reward_type_id = $typeId  // مثل referral_id
            description = $description
}
```

**أمثلة:**

```php
// إضافة نقاط (دعوة صديق)
$rewardsService->addPoints(
    $userId = 123,
    $points = 100,
    $type = 'friend_invite',
    $typeId = 456,  // referral_id
    $description = 'دعوة صديق: أحمد'
)

// إضافة نقاط (أيام متتالية)
$rewardsService->addPoints(
    $userId = 123,
    $points = 50,
    $type = 'consecutive_days',
    $typeId = null,
    $description = 'استخدام المنصة لـ 5 أيام متتالية'
)

// خصم نقاط (استخدام أداة AI)
$rewardsService->addPoints(
    $userId = 123,
    $points = -30,  // سالب للخصم
```
